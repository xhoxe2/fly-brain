# FLY//BRAIN

Read `docs/routes.md` before exploration. Known file → open it; exact symbol →
`rg`; documentation concepts → QMD when indexed. Keep Ponytail in full mode.

No backend, runtime API tokens, per-neuron Object3D, fabricated scientific
connections, or decorative changes before performance verification.
Raw scientific sources belong in ignored `.cache/`, not public assets or Git.
Run `npm test`, `npm run build`, and the Python data self-check for logic/data
changes. Verify rendering and interactions in a real browser.

The user sets environmental conditions; behavior must arise from continuously
computed neural dynamics and motor outputs. Never substitute scripted choices,
graph-traversal animations, or an LLM policy and describe them as the fly's brain.
Identify measured anatomy, neural-model assumptions, sensory encoding and body
actuation separately. State limitations before treating a demonstration as an
autonomous embodied brain; attractive rendering is not evidence of this.
